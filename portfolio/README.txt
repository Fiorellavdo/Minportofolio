PORTFOLIO – Fiorella Proos Di Giulio
=====================================

MAPPSTRUKTUR:
portfolio/
├── index.html       ← öppna den här i webbläsaren
├── style.css        ← all styling
├── script.js        ← all JavaScript
├── README.txt       ← den här filen
└── images/
    ├── vai/         ← lägg dina VAI-bilder här
    ├── evity/       ← lägg dina Evity-bilder här
    ├── silva/       ← lägg dina Silva/Primus-bilder här
    ├── ihm/         ← lägg dina IHM-bilder här
    └── eget/        ← lägg dina egna projekt-bilder här

HUR DU LÄGGER TILL BILDER:
1. Lägg bilden i rätt mapp (t.ex. images/evity/kampanj1.jpg)
2. Öppna script.js
3. Hitta sektionen du vill lägga till bilden i (t.ex. // VAI BILDER)
4. Lägg till bilden enligt exemplet i script.js

STARTA MED LIVE SERVER I VS CODE:
1. Installera tillägget "Live Server"
2. Högerklicka på index.html
3. Välj "Open with Live Server"
